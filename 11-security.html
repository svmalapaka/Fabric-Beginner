Why Security Matters

Data is the most valuable asset in any organization. Fabric ensures that data is protected, governed, and monitored across all workloads.

Key Security Concepts

1. Role-Based Access Control (RBAC)

RBAC defines who can access what. Permissions apply at workspace, item, folder, and table levels.

2. Domains

Domains organize data by business area — Finance, Sales, HR, Operations. They simplify governance and permission management.

3. Sensitivity Labels

You can classify data as:

  • Public
  • Confidential
  • Highly Confidential
  • Restricted

Labels flow across Fabric items, including Power BI reports.

4. Lineage

Fabric tracks where data comes from and how it moves. This helps with audits, compliance, and debugging.

5. Monitoring & Auditing

Fabric logs:

  • Access events
  • Data changes
  • Pipeline runs
  • Notebook executions
  • Security violations

Perfect for compliance and operational oversight.

Beginner Scenario: Water Filter Example

A company selling refrigerator filters must protect:

  • Customer data
  • Order history
  • Payment information
  • Inventory systems

Fabric ensures only authorized teams can access sensitive data.
