What Is the Lakehouse?

The Lakehouse is your unified analytics workspace. It combines the flexibility of a data lake with the structure of a data warehouse.

Engineers, analysts, and data scientists all work here — using files, tables, notebooks, SQL, and machine learning in one place.

Why the Lakehouse Matters

Traditional systems split work across multiple tools:

  • Data engineers use Spark
  • Analysts use SQL
  • Data scientists use notebooks
  • BI teams use dashboards

The Lakehouse unifies all of these into a single workspace backed by OneLake.

Key Features

1. Delta Tables

Delta tables provide ACID transactions, schema evolution, and time travel — essential for reliable analytics.

2. SQL Endpoints

Business teams can query Lakehouse tables using familiar SQL without needing Spark knowledge.

3. Notebooks

Python, Spark, and ML workflows run directly inside the Lakehouse.

4. File + Table Unity

Files and tables live together. You can convert files to tables instantly — no ETL required.
