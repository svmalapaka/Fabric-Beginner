What Is Data Science in Fabric?

Fabric integrates data science directly into the Lakehouse. You can run notebooks, train models, engineer features, and deploy scoring pipelines — all backed by OneLake.

Why It Matters

Traditional ML workflows require multiple tools:

  • One tool for data prep
  • Another for notebooks
  • Another for training
  • Another for deployment

Fabric unifies all of this into one workspace.

Key Components

1. Notebooks

Python and Spark notebooks run directly inside the Lakehouse. Perfect for data exploration, feature engineering, and ML experiments.

2. ML Training

You can train models using:

  • Scikit-learn
  • PyTorch
  • TensorFlow
  • Spark MLlib

All training data comes directly from OneLake.

3. Feature Store

Fabric supports reusable features — shared across teams and models. This prevents duplication and ensures consistency.

4. Scoring Pipelines

Models can be deployed for:

  • Batch scoring
  • Real-time scoring
  • Dashboard integration

Beginner Scenario: Water Filter Example

A model can predict:

  • Which filter a customer is likely to need
  • Which products are frequently bought together
  • Which customers need reminders for replacements

All trained using Lakehouse data.

Professional Insight

Fabric’s ML layer is ideal for:

  • Demand forecasting
  • Recommendation systems
  • Fraud detection
  • Predictive maintenance
  • Customer segmentation

And because everything lives in OneLake, ML workflows are simpler, faster, and more reliable.
