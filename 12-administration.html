Admin Portal

The Admin Portal provides centralized control over Fabric resources, capacities, and governance settings.

Monitoring Dashboards

Fabric includes built-in dashboards to track:

  • Pipeline runs
  • Notebook executions
  • Warehouse queries
  • Lakehouse operations
  • Real-time event streams

These dashboards help administrators detect issues early.

Capacity Management

Administrators can allocate and monitor compute capacity across workloads:

  • Lakehouse
  • Warehouse
  • Real-Time Analytics
  • Data Science

Proper capacity management ensures performance and cost efficiency.

Alerts & Notifications

Alerts can be configured for:

  • Failed pipeline runs
  • High query latency
  • Capacity overload
  • Security violations

Alerts help teams respond quickly to operational issues.

Beginner Scenario: Water Filter Example

A company selling refrigerator filters can monitor:

  • Inventory updates
  • Search trends
  • Pipeline refresh failures
  • Warehouse query performance

This ensures smooth operations and customer satisfaction.

Professional Insight

Administration and monitoring are essential for maintaining reliability, performance, and cost control across Fabric workloads.
