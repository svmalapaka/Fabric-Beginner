What Are Pipelines?

Pipelines are Fabric’s workflow engine. They let you connect to data sources, ingest data, transform it, schedule jobs, and orchestrate complex analytics processes — all without leaving Fabric.

Why Pipelines Matter

Every analytics system needs automation:

  • Daily ingestion jobs
  • Scheduled transformations
  • Data quality checks
  • Model retraining workflows
  • Dashboard refresh pipelines

Pipelines unify all of this inside Fabric, eliminating external ETL tools and reducing complexity.

Key Features

  • Dataflows: Low-code transformations for business users.
  • Copy Activities: Move data from external sources into OneLake.
  • Notebook Tasks: Run Python/Spark notebooks as pipeline steps.
  • Scheduling: Automate daily, hourly, or event-driven workflows.
  • Monitoring: Track pipeline runs, failures, and performance.
